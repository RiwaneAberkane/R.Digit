# R.Digit

Portfolio professionnel de **R.Digit**, dédié à la création de sites web modernes, performants et sur mesure.

## Stack

- React
- Vite
- React Router
- GSAP / ScrollTrigger
- React Helmet Async
- Lucide React
- React Icons

## Commandes

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
```
